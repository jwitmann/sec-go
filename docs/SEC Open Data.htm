Good to Know

กองทุนรวม (Mutual Fund) คือ เครื่องมือในการลงทุนรูปแบบหนึ่งที่เปิดโอกาสให้ผู้ลงทุนหลายรายนำเงินมารวมกันเป็น “กองทุน” และมอบหมายให้ผู้เชี่ยวชาญด้านการลงทุน ซึ่งก็คือ บริษัทหลักทรัพย์จัดการกองทุน (Asset Management Company: AMC) ที่มีความเชี่ยวชาญในการจัดการลงทุนและได้รับใบอนุญาตจากสำนักงาน ก.ล.ต. เป็นผู้บริหารจัดการเงินลงทุนดังกล่าว บลจ.จะนำเงินของกองทุนไปลงทุนในสินทรัพย์ประเภทต่าง ๆ เช่น หุ้น ตราสารหนี้ เงินฝาก หรือสินทรัพย์อื่น ๆ ตาม นโยบายการลงทุน และ วัตถุประสงค์ของกองทุน ที่กำหนดไว้ เพื่อให้ผู้ลงทุนสามารถบรรลุเป้าหมายทางการเงินที่คาดหวัง

ศึกษาข้อมูลเพิ่มเติมเกี่ยวกับกองทุนรวมได้ที่ : https://insight-fund.sec.or.th/mutual-fund-info/what-is-mutual-fund

Fund API ให้ข้อมูลอะไรบ้าง

SEC Open API : Fund API ให้บริการข้อมูลเกี่ยวกับกองทุนรวมในหลายมิติ ครอบคลุมตั้งแต่ข้อมูลบริษัทหลักทรัพย์จัดการกองทุน ไปจนถึงข้อมูลผลการดำเนินงาน ข้อมูลพอร์ตลงทุน และข้อมูลรายวันของกองทุน โดยสามารถแบ่งกลุ่มข้อมูลสำคัญได้ดังนี้

ข้อมูลบริษัทหลักทรัพย์จัดการกองทุน หรือ บลจ. (Asset Management Company - AMC)

ได้แก่ รายชื่อบริษัทหลักทรัพย์จัดการกองทุนในประเทศไทย

ข้อมูลโครงการของกองทุนรวม (Fund General Information)

เช่น ลักษณะทั่วไปของกองทุน สถานะกองทุน นโยบายการลงทุน ลักษณะโครงการ อายุโครงการ ประเภทกองทุนรวมตามลักษณะพิเศษ ผู้เกี่ยวข้องกับกองทุน รวมถึงข้อมูลชนิดหน่วยลงทุน (Share Class) และค่าธรรมเนียมต่าง ๆ

ข้อมูลจากหนังสือชี้ชวนส่วนสรุปข้อมูลสำคัญของกองทุน (Fund Factsheet)

เช่น ผลการดำเนินงาน (Performance) สัดส่วนการลงทุนตามประเภทสินทรัพย์ (Asset Allocation) และข้อมูลเชิงสถิติของกองทุนรวม (Statistics)

ข้อมูลการลงทุนของกองทุนรวมตามรอบระยะเวลา

เช่น ข้อมูลการลงทุนของกองทุนรวม ณ วันทำการสุดท้ายของแต่ละไตรมาส และสัดส่วนการลงทุนของกองทุนรวมตามประเภทสินทรัพย์ ณ วันทำการสุดท้ายของแต่ละเดือน

ข้อมูลกองทุนรวมรายวัน (Daily Fund Data)

ได่แก้ มูลค่าทรัพย์สินสุทธิ (NAV) รายวัน และประวัติการจ่ายเงินปันผลของกองทุนรวม

NOTE

รายละเอียดของข้อมูลและฟิลด์ที่ได้รับในแต่ละ API จะขึ้นอยู่กับ endpoint ที่ผู้ใช้งานเลือกเรียกใช้

ทำความเข้าใจระดับข้อมูล (AMC vs Fund vs Share Class)

เพื่อให้ผู้ใช้งานสามารถเรียกใช้และตีความข้อมูลได้อย่างถูกต้อง ควรทำความเข้าใจว่า Fund API มีการจัดโครงสร้างข้อมูลเป็น 3 ระดับหลัก ดังนี้

AMC (ระดับบริษัทจัดการกองทุน)

เป็นข้อมูลระดับบริษัทหลักทรัพย์จัดการกองทุน ซึ่งใช้เป็นจุดเริ่มต้นในการค้นหากองทุนรวมภายใต้การบริหารจัดการของแต่ละบริษัท

Fund (ระดับกองทุน)

เป็นข้อมูลภาพรวมในระดับกองทุน เช่น ลักษณะทั่วไปของกองทุน ประเภทกองทุนรวมตามลักษณะพิเศษ และข้อมูลการลงทุนของกองทุนรวม (Fund Portfolio)

Share Class (ระดับชนิดหน่วยลงทุน)

เป็นข้อมูลที่แยกตามชนิดหน่วยลงทุนของกองทุนเดียวกัน เช่น ข้อมูลจาก Fund Factsheet รวมถึงข้อมูลกองทุนรวมรายวัน ได้แก่ NAV และประวัติการจ่ายเงินปันผล

NOTE

กองทุนเดียวกันสามารถมีได้มากกว่าหนึ่ง Share Class หรือ ชนิดหน่วยลงทุน โดย AMC อาจกำหนดการแบ่งชนิดหน่วยลงทุนตามเงื่อนไขที่แตกต่างกัน เช่น

  • นโยบายการจ่ายเงินปันผล

  • ประเภทผู้ลงทุน

  • เงื่อนไขการขายและรับซื้อคืนหน่วยลงทุน

  • นโยบายป้องกันความเสี่ยงจากอัตราแลกเปลี่ยนเงินตราต่างประเทศ (Currency-Hedged Share Class)

How to Use Fund API

The Fund API consists of multiple endpoints that are connected according to the fund data structure. Retrieving data in a step-by-step sequence helps users access the required information accurately and efficiently.

Step 1: Start with the list of Asset Management Companies (AMC)Diagram

Start by calling the API List of Asset Management Companies (AMC) to retrieve the list of AMCs and obtain the `unique_id` of the desired asset management company. The `unique_id` can then be used as the `company_info` parameter in Mutual Funds Managed by the AMC and General Fund Information to retrieve all mutual funds managed under that AMC.

/v2/fund/general-info/amcs
output
unique_id
next
/v2/fund/general-info/profiles?company_info={unique_id}
Step 2: Retrieve Fund List and Share ClassesDiagram

Retrieve the list of funds managed by the selected AMC from Mutual Funds Managed by the AMC and General Fund Information . Users will receive information about the funds under the selected AMC, including key fields such as `proj_id : fund project ID` and `fund_class_name : share class name`. These values can then be used as parameters when calling other Fund APIs to retrieve more detailed information such as Factsheet, Performance, NAV, Portfolio, and Asset Allocation.

/v2/fund/general-info/profiles
output
proj_id / fund_class_name
next

Parameter Usage Guidelines

By design, the parameters of each Fund API endpoint are optional, unless otherwise specified in certain cases.

กล่าวคือ

  • หากผู้ใช้งาน ไม่ระบุพารามิเตอร์ใด ๆ ระบบจะส่งคืนข้อมูลทั้งหมดที่มีอยู่ใน endpoint นั้น

  • หากผู้ใช้งาน ระบุพารามิเตอร์ ระบบจะส่งคืนเฉพาะข้อมูลที่ตรงตามเงื่อนไขที่กำหนด

This approach supports two main usage patterns:
1. Full extraction

For users who want to retrieve all available data to store in their database or process within their own systems.

GET /v2/fund/general-info/profiles
2. Selective retrieval

For users who want to retrieve only specific data of interest by using parameters to narrow down the results.

GET /v2/fund/general-info/profiles?amc_id=xxxx
NOTE

เว้นแต่จะระบุไว้เป็นอย่างอื่น ผู้ใช้งานสามารถเลือกได้ว่าจะเรียกข้อมูลทั้งหมดจาก endpoint นั้น หรือจะระบุพารามิเตอร์เพื่อดึงเฉพาะข้อมูลที่ต้องการใช้งาน

Best Practices for Data Retrieval

NOTE

การดึงข้อมูล Fund API ในการใช้งานจริง มักต้องใช้การเขียนโปรแกรมแบบ Loop ตามรายการ `proj_id` และ/หรือ `fund_class_name` ที่ได้รับจาก api กองทุนรวมภายใต้การบริหารจัดการของบลจ.และลักษณะทั่วไปของแต่ละกองทุน(/v2/fund/general-info/profiles) โดยเฉพาะกรณีที่ผู้ใช้งานต้องการดึงข้อมูลจากหลายกองทุนหรือหลายชนิดหน่วยลงทุนในคราวเดียว

TIP

หากต้องการนำข้อมูลไปใช้งานต่อในระบบวิเคราะห์ข้อมูลหรือสร้างฐานข้อมูลภายใน แนะนำให้เริ่มจากการดึงข้อมูลแบบเต็มชุด (full extraction) จาก endpoint ต่าง ๆ แล้วจึงออกแบบกระบวนการอัปเดตข้อมูลเฉพาะส่วนที่จำเป็นในลำดับถัดไป
